# Claude Skills for Real Estate (starter set)

Seven copy-and-paste skills real estate professionals use every day, covering the full transaction cycle: lead qualification, listing copy, market analysis, client follow-up, contract-terms review, neighborhood guides, and investment math.

Stop spending hours on tasks an assistant handles in minutes. Each skill is a self-contained prompt you paste into Claude, ChatGPT, or any assistant, then feed your real input. No code required.

## The seven skills

1. Lead Qualifier
2. Property Description Generator
3. Market Analysis Reporter
4. Client Follow-Up Scheduler
5. Contract Terms Analyzer
6. Neighborhood Guide Creator
7. Investment Property Calculator

All seven live in [`SKILL.md`](./SKILL.md). Copy the block you want and go.

## Tune them to you

These are generic starters on purpose. The parts that make them yours (your source-quality weights for scoring leads, your expense assumptions for the investment math, your voice for the copy) are left as placeholders. Fill them in.
